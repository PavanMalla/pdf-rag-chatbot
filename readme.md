# PDF RAG Chatbot

Ask questions about uploaded PDF documents using
retrieval-augmented generation (RAG).

## Features

- PDF text extraction
- Semantic embeddings
- FAISS similarity search
- Hugging Face language model inference
- Gradio user interface

## Configuration

Configure HF_TOKEN and HF_MODEL in the Space
Settings. Never commit private API tokens.
